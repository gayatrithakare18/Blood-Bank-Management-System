# Blood Bank Management System

## Project Overview
The Blood Bank Management System is a console-based application developed using Core Python and SQLite. It is designed to manage donor information, record blood donations, maintain blood inventory, and handle patient blood requests.

## Features
- Add and view blood donor details.
- Search donors by blood group.
- Record blood donations.
- Manage blood inventory.
- Register patient blood requests.
- View blood request history.
- Track pending and issued requests.

## Technologies Used
- Python
- SQLite Database
- Object-Oriented Programming (OOP)

## Python Concepts
- Variables and data types
- Conditional statements
- Loops
- Functions
- Classes and objects
- Exception handling
- Database connectivity
- SQL queries (CRUD operations)

## How to Run
1. Install Python.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Run `python main.py`.

The SQLite database is automatically created when the application runs.
